WHY IT MATTERS

01 / AUTOMATE

사람이 반복하던 관리 과정을 시스템이 반복합니다.

02 / CROP SPECIFIC

작물별 기준값을 환경 제어에 연결합니다.

같은 시스템이라도 인삼과 고추, 더덕과 비트의 환경 기준이 같지 않다는 전제에서 출발합니다.

03 / ACCESSIBLE

필요한 부분부터 자동화합니다.

농가의 기술적·경제적 진입장벽을 낮추면서 실제 관리 작업에 직접 연결되는 기능부터 구성합니다.

HOW IT WORKS

측정하고, 판단하고,
작동합니다.

SENSECOMPARECONTROLREPEAT
01 / SENSE

환경을 읽습니다.

센서가 육묘 공간의 온도, 습도, 토양수분, CO₂ 상태를 확인합니다.

02 / COMPARE

작물의 설정값과 비교합니다.

현재 환경이 작물에 맞게 설정한 범위 안에 있는지 확인합니다.

03 / CONTROL

필요한 장치를 작동합니다.

토양수분이 부족하면 관수 시스템을 작동시키고 환경조건에 따라 팬과 기타 장치를 제어합니다.

04 / REPEAT

그리고 다시 확인합니다.

환경을 다시 측정하고 설정값과 비교하는 과정을 반복합니다.

SENSE → COMPARE → CONTROL → REPEAT

ABOUT SEEDSYNC

작물을 이해하고,
시스템을 설계하는 SeedSync입니다.

원예 연구를 통해 작물의 생육환경을 이해하고, 하드웨어 설계를 통해 실제 농업 현장에서 작동하는 시스템으로 구현합니다.

01 / HORTICULTURE

작물을 이해합니다.

논문과 농업자료를 기반으로 종자별 발아 조건과 작물별 생육환경을 조사합니다.

02 / ENGINEERING

환경을 시스템으로 구현합니다.

센서, 릴레이, 타이머, 펌프, 팬 등을 활용해 작물 데이터를 실제 제어 시스템으로 연결합니다.
